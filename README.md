# Piltaland core identity
# ピルタランド国家概要法
This repository defines the core identity of Piltaland. 本リポジトリは、ピルタランドの国家としての同一性（言語、シンボル、および基本理念）を定義する原典です。

## Contents / 定義内容
Official Language (LANGUAGE.md): English (Primary) & Japanese (Secondary)
公用語 (LANGUAGE.md): 英語(第一)、日本語(第二)


## Status / 法的状態
This "Piltaland Core Identity" is the highest law below the Grand Charter. 本法は「大憲章」に次ぐ、国家の根幹を成す法律として運用されます。
